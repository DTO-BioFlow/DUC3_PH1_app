PLET

Plankton Lifeform Extraction Tool (PLET) is a central repository for lifeform abundances. Users can submit their on-species level data toghether with traits description. The description is added in the master list: Plankton lifeform traits master list, and it is by this masterlist that lifeform classification takes place.

It is adviced for all dataset managers to contribute their data to PLET. It is a central repository for this information and an important node in the pelagic habiatat assessment.

From a user perspective it handles several functionalities such as the spatial and temporal aggragation of abundances. PLET allows users to manualy perform downloads. There is no API available but there is a basic python endpoint.

Harvest PLET library

A Python library build around the PLET endpoint. It offers additional functionality to request data aggregated according the OSPAR Common Procedure Assessment Units.
  • Make programmatical request to the PLET database for indivudual datasets.
  • Request all datasets aggregated according the common precedure assessment usnits.
